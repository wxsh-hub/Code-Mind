# 数据库编码规范

## 表设计规范

### 表名
- 使用小写字母和下划线，如 `user_order`、`product_category`
- 使用单数形式，如 `user` 而不是 `users`
- 前缀标识业务模块，如 `sys_user`、`biz_order`

### 字段名
- 使用小写字母和下划线，如 `create_time`、`user_id`
- 布尔字段使用 `is_` 前缀，如 `is_deleted`、`is_enabled`
- 时间字段使用 `_time` 后缀，如 `create_time`、`update_time`

### 主键
- 使用 `id` 作为主键名
- 类型为 `BIGINT`
- 使用自增或雪花算法

### 必备字段
```sql
id          BIGINT       PRIMARY KEY AUTO_INCREMENT,
create_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
update_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
create_by   VARCHAR(64)  DEFAULT '',
update_by   VARCHAR(64)  DEFAULT '',
deleted     TINYINT      NOT NULL DEFAULT 0,
```

## 索引规范

### 索引命名
- 主键：`pk_table_name`
- 唯一索引：`uk_table_name_field`
- 普通索引：`idx_table_name_field`

### 索引原则
1. 单表索引不超过 5 个
2. 区分度低的字段不要建索引（如性别）
3. 联合索引遵循最左前缀原则
4. 避免在索引列上使用函数

## SQL 规范

### 查询优化
```sql
-- ❌ 错误：使用 SELECT *
SELECT * FROM user WHERE id = 1

-- ✅ 正确：明确字段
SELECT id, username, email FROM user WHERE id = 1
```

### 分页查询
```sql
-- ❌ 错误：大偏移量
SELECT * FROM user LIMIT 100000, 10

-- ✅ 正确：使用游标分页
SELECT * FROM user WHERE id > 100000 LIMIT 10
```

### 批量操作
```sql
-- ❌ 错误：逐条插入
INSERT INTO user (name) VALUES ('a');
INSERT INTO user (name) VALUES ('b');

-- ✅ 正确：批量插入
INSERT INTO user (name) VALUES ('a'), ('b'), ('c');
```

## MyBatis 规范

### XML 映射
- 每个 Mapper 对应一个 XML 文件
- 使用 `<sql>` 片段复用通用字段
- 使用 `<where>` 自动处理 AND/OR

### 动态 SQL
```xml
<select id="selectUsers" resultType="User">
    SELECT id, username, email
    FROM user
    <where>
        <if test="username != null and username != ''">
            AND username LIKE CONCAT('%', #{username}, '%')
        </if>
        <if test="status != null">
            AND status = #{status}
        </if>
    </where>
    ORDER BY create_time DESC
</select>
```

## 事务规范

### 事务粒度
- 事务尽量小，不要在事务中做远程调用
- 只读查询使用 `@Transactional(readOnly = true)`
- 设置合理的超时时间

### 事务传播
- 默认使用 `REQUIRED`
- 查询方法使用 `SUPPORTS`
- 嵌套事务使用 `NESTED`

## 安全规范

### SQL 注入防护
- 使用参数化查询，不要拼接 SQL
- 使用 MyBatis 的 `#{}` 而不是 `${}`
- 对用户输入进行校验和转义

### 敏感数据
- 密码使用 BCrypt 加密
- 手机号、身份证号脱敏存储
- 日志中不要打印敏感信息
