# Code-Mind 前端页面设计方案

## 页面功能清单

| 模块 | 页面 | 功能 | 优先级 |
|:---|:---|:---|:---|
| 知识库 | 知识库列表 | 查看、创建、删除知识库 | P0 |
| 知识库 | 文档管理 | 上传、查看、删除文档 | P0 |
| 知识库 | 分块预览 | 查看分块结果和元数据 | P1 |
| 元数据 | 模块管理 | CRUD 模块 | P1 |
| 元数据 | 功能管理 | CRUD 功能（关联模块） | P1 |
| 审核 | 矛盾审核 | 查看、审核矛盾对 | P0 |
| 问答 | 智能问答 | 输入问题、查看 AI 回答 | P0 |
| 设置 | 系统设置 | 模型、检索、MCP 配置 | P2 |

## 版本对比

| 特性 | 版本一（极简） | 版本二（专业） | 版本三（仪表盘） |
|:---|:---|:---|:---|
| 页面数量 | 4 个 | 6 个 | 5 个 |

## 推荐方案

**推荐版本一（极简风格）**，原因：
1. 开发成本低，快速上线
2. 专注核心功能，用户体验好
3. 后续可迭代升级到版本二/三

### 技术栈建议
- **前端框架**: React 18 + TypeScript
- **UI 组件库**: Ant Design / Arco Design
- **状态管理**: Zustand
- **路由**: React Router v6
- **HTTP 客户端**: Axios
