## 数据流

### 上传知识
```
AI/MCP Gateway
    ↓
upload_memory / upload_skill
    ↓
ragent API
    ↓
分块 + 向量化
    ↓
PostgreSQL (pgvector)
```

### 查询知识
```
AI/MCP Gateway
    ↓
ask_project / search_experience
    ↓
ragent API
    ↓
向量检索 + 关键词检索
    ↓
返回结果（含 metadata、置信度）
```

### 删除知识
```
AI/MCP Gateway
    ↓
delete_vector / delete_feature / delete_module
    ↓
ragent API
    ↓
删除向量 + 级联删除
```
